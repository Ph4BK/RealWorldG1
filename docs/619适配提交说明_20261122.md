## 619 专用配置与参数来源

| 配置 | 当前值及来源 |
|---|---|

| 初始高度 | 1.24 m，来源为 11-19 卷尺测雷达球壳中心，经用户同意近似 IMU 高度；不是独立测量的 IMU 真值。XY/yaw 每次按实际位置选择 |
| 静态图 | 5 cm 格网，400×474；清洁图逐字节继承，独立房间外禁行 87,894 格。旧地图时效和 G1 更高障碍覆盖仍需现场核验 |
| 膨胀 | 5 格=0.25 m，沿用用户选择，不是 Go2 的 0.35 m，也不代表完整 G1 肢体扫掠已覆盖 |
| 动态窗口 | 10 帧累计、min_points=2，高度 0.05～1.30 m，更新圆环 0.3～2.0 m；沿用当前配置，非真/假点可分性的实测阈值 |
| 时效 | 控制位姿 0.30 s，传感器 1.0 s、注册 6.0 s；沿用工程门限，非延迟认证。参考包心跳不能续旧 ICP 寿命 |
| 变换重置 | 沿用 0.25 m/10°；活动任务跨定位会话/地图代次取消，不能用旧动作继续 |
| 普通转后等待 | 原 0.75 s 最短等待 + 0.30 s 角速度窗，0.15 rad/s 门，额外最多 1.5 s；现场新增，尚未标定为安全停稳阈值 |

`static_test` 是人工监督的消融模式，没有新增障碍保护。新旧位姿节点需配套更新；新导航没有新参考包时拒绝使用旧显示位姿，不自动回退。参考有效期使用同宿主 monotonic 时钟，不支持不加修改地跨主机部署。

地图包 `provenance/` 是生成时的原始快照，其文件名不是来源机器/部署版本的额外证明；运行应使用顶层 `tools/`，不能把快照脚本覆盖回当前实现。历史来源路径保留作溯源，离线重建可显式传 `--source-pcd`、`--source-grid`、`--source-readme`，使用随包 PCD 与 provenance 原件。

## 已有测试与真机验证

11-21 本地 WSL ros2 conda 专项为 175 passed＋33 subtests；全套为 354 passed、1 failed＋106 subtests。既有失败是 `test_pose_replay_button.py::ButtonTest::test_button_only_start_and_reload` 缺历史 bag 启动 IMU，不称全绿。提交前复跑结果及命令见[本次测试记录](619适配测试记录_20261122.md)。

节点测试使用隔离 ROS domain、localhost 和拦截的运动发布出口，不连接 G1。真实历史 L3 只验证源选择/XYZ 映射，不是修改后新闭环轨迹。移植测试使用本地生成的 Action 与 Unitree 消息包及 Python 依赖，不把消息构建/依赖目录提交进源码。

11-21 现场记录中有三趟 arrived，最终内部 XY 误差分别约 23.3 cm、5.9 cm、15.2 cm；各趟开关与源码并不完全相同，不能统称本次提交的统一版本验收。这些是导航定位读数，不是独立物理真值。后续记录表明控制源已选择 latest_fastlio，但仍有转向/路径异常。`arrived` 继续只表示流程完成并下发停止，**不保证请求 pos_tol/yaw_tol 或物理停稳**；朝向误差由最终位姿计算，位置内部误差随结果返回。

## 已知问题与尚未实施的建议

| 优先级 | 已知情况 | 建议与验收方向 |
|---|---|---|
| P0 | 转后等待按 yaw 变化而非新源帧记历史；窗口不足直接放行，额外超时也放行 | 按新源帧采样并清会话历史，持续低角速度且新鲜才准入；未知/超时零速并报告 |
| P0 | 停转不代表朝向正确；真实控制入口合成测试偏约 28.7°仍前进 | 走前重算当前 XY→固定 STG，方向不合格不发前进；有界重对准策略另行审核 |
| P0 | 普通 walk 固定 vx=0.5、wz=0，缺航向/横向/无进展停车 | 增加偏离停车，避免检查指向 STG 的通道而实际沿错误机头前进 |
| 功能条件门 | 无完整 G1 机身动作扫掠；扇区点少不证明转向/脱困路径空净 | 贴障转向或自动恢复前实测身体/肢体包络并验扫掠；当前受阻默认硬拒绝，不自行恢复 |
| P1 | 生产规划入口独立复现 STG 跨 pre 约 22 cm | 在 macro rollout 内截断安全可见终点并正确交接；不是每趟大转角均由此导致 |
| 恢复动态功能前 | 融合存在稀疏假占据；低反射/低物体也可能是真的 | 连续原始帧与真椅腿/低障碍回归，验证空间支持/独立帧命中，不盲搬 Go2 反射率门 |
| 恢复动态功能前 | 圆环外和盲区保留 task；pause 保留、reset 恢复静态图及固定禁行，非全局 2 s TTL | 明确跨任务、reset、地图参考更新与移走物体的生命周期；不能把未观测当空净 |
| P1 | 最新源解耦不证明绝对延迟为零，旧显示仍滞后 | 被动记录源 header/接收/参考矩阵，审计端到端时序；不放宽原健康门 |
| P1 | 末端误差含横向、余动、参考点变化、定位更新等 | 分量测量后标定，不把最终欧氏误差直接填入 coast |
| P2 | 无障碍距离软代价；小角度两段转向收益待比较 | 对真实 FMM/STG 做 A/B。两段策略原意是放大转角再返回以减少小角度停转过冲，不重复追问动机；先解决取样/准入，再评估效果 |

业务桌前站位参考点、操作接管与容差分工交由任务规划组讨论，不在本 PR 冻结新接口。以上建议未在本次顺手实施，不把“已记录”当“已修复”。
